# Implantacao em nova maquina

1. Instale Node.js 20 ou superior.
2. Copie o projeto e execute `INSTALAR.bat`.
3. Configure o Firebird em `%ProgramData%\Dashboard\database_config.json` ou
   pela tela de configuracao do banco.
4. Valide `http://localhost:506/api/status`.
5. Para iniciar junto com o Windows, execute `INSTALAR_SERVICO.bat` como Administrador.

Python e Flask nao sao necessarios para instalar ou executar a aplicacao.
